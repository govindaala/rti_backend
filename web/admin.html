सुरक्षा सूचना

यह अभी UI skeleton है। वास्तविक Admin login, role authorization और audit logging लागू होने तक इसे सार्वजनिक उत्पादन में उपयोग न करें। केवल UI में पासवर्ड डालने से सुरक्षा नहीं बनती।

01API जाँच

Backend स्थिति

स्वास्थ्य endpoint से backend उपलब्धता जाँचें।

02लंबित

कानूनी ज्ञान समीक्षा

नए निर्णय, citations, पैरा और सत्यापन स्थिति की समीक्षा।

03लंबित

रिसर्च कार्य कतार

सरकारी स्रोत, crawler jobs, retries और worker checkpoints।

04लंबित

Applicant/PIO roles, subscription और quota management।

05लंबित

सिस्टम लॉग और सुरक्षा

प्रवेश लॉग, त्रुटियाँ, सहमति रिकॉर्ड और audit trail।

06लंबित

Code Development AI

अलग branch पर बदलाव, tests, security checks और merge approval।
